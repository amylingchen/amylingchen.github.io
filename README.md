# Lingling Chen Academic Homepage

Static academic homepage, ready for GitHub Pages.

## Deploy to GitHub Pages

1. Create a repository named `amylingchen.github.io` under the `amylingchen` account.
2. Upload every file and folder in this package to the repository root.
3. Commit to the default branch (`main`).
4. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
5. The site will be available at `https://amylingchen.github.io/` after GitHub finishes deployment.

For a project repository instead, use the same Pages settings. Relative asset paths are already compatible with a project subpath.
